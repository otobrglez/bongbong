# PRD: tap based navigation and gameplay

My ambition is to port this game to non-keyboard devices such as mobile phones, ipads etc.
These devices don't have keys that are nesecery to operate this game.

So as part of this PRD I want to explore "tap based" gameplay/navigation.

In simple terms. User should tap on screen (or click) and engine should then send tank to that location (via pathfinding?) if enemy tank is located there it should shoot at it (if in range) or it should move close by (in range). So we are taling more about assistend moving and shooting.
