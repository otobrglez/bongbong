Concept lab · level 0 · before Lotus Lagoon

BOOT CAMP

A first training stage that teaches driving, crates, firing, the frog and the first enemy in about three minutes, with your frog as the only guide. Drive it below with ARROWS or WASD and SPACE. Switch KEYS / TOUCH on the right to hear how the frog's words change. Nothing here is engine code yet.

0:00 A 48 x 13 field map: the camera follows you. A red arrow at the edge points to a tank off screen, a green one to the frog.

DECIDED

  • Frog guide only. No signs, paint or HUD card.
  • Short lines, no name. Eight words or fewer once enemies are out.
  • Level 0, skippable. Tile 0 in the level select.
  • All six beats. About three minutes.
  • Field map, 48 x 13. The camera follows.

HINTS NAME

The game already flips its words between keys and taps (hud::Hints). The frog's lines follow the same switch.

BEATS

    01 · The course

    Six beats, one new thing each

    Each pen teaches one idea and the gate out of it opens only when the player has done it once. Nothing is read before it is needed, and every lesson is something the player does rather than something they are told.

    BEATTEACHESDONE WHENFROG SAYSENGINE
    02 · The frog's voice

    Rules for every line

    With signs and the HUD card out, the frog carries every rule. These keep it readable in a fight and cheap to translate.

    LENGTH

    Eight words, then less

    A line is at most eight words, and in beats 5 and 6 four or fewer. The bubble reveals word by word and stays up for as long as the line needs to be read.

    INPUT

    Keys or taps, never both

    A line that names a control has a keys and a touch version, picked by the input last used (hud::Hints). SPACE becomes "tap the right half".

    NUDGE

    Repeat the point when stuck

    After 14 seconds with nothing said, the frog repeats the one thing the beat needs ("The ammo crate is up north."). This replaces the signs a lost player would have reread.

    OFF SCREEN

    A green arrow to the frog

    When the frog is out of view, a green arrow at the edge points to it and carries a FROG tag while it talks. It's the same arrow kind the indicators already draw for frogs.

    03 · More to try

    Ideas parked for later

    • Ghost demo tankA translucent tank drives the pen's lesson once (a slide into a turn, a shot at the wall), then fades. Shows momentum better than words.
    • No failure, only a gateDown in training puts you back at the last gate with full health, as here. A lost frog replays the beat, not the course.
    • Par time and a medalThe round clock already exists. A bronze, silver and gold time gives returning players a reason to replay level 0.
    • Signs laterIf the frog alone proves too little, signposts are the cheapest add-on: a map cell and a card, and the builder could place them too.
    • Dummy tanksThe first enemy shoots only at the frog and never at the player, so the first fight is about protecting rather than surviving.
    • Hide in the grassA bonus pen with tall grass and an enemy that loses sight of you. Teaches concealment, which no level spells out today.
    • Couch and onlineTwo seats share the course; each gate waits for both tanks. Online, the room runs the script and signs travel as map cells.
    04 · How it would land

    Engine sketch

    Training is a field map like any other, plus a short script. Most of what the course needs exists: crates, air drops, gates, the frog, waves, the follow camera, the Hints switch. New are beat triggers, doors that open on a beat, a scripted frog path and its speech bubble.

    • Map cell: door, an iron run bound to a beat that slides open when the beat is done.
    • Script: a [training] list of beats, each a trigger (flags, collect, destroy, heal_frog, kill) and what it starts (open a door, drop a crate, roll a tank in through a gate).
    • Mission: Mission::Training, so the end screen says TRAINING COMPLETE and leads to level 1. First in levels.toml as boot-camp; a progress file already past level 1 opens on Lotus Lagoon.
    • Frog: each beat names a spot; the frog hops there through the open doors and says the beat's lines (say, with keys/touch variants and a nudge). The bubble is a new painter beside the HUD.
    • Words: frog-* keys in lang/en.ftl and sl.ftl, held to the bubble's width by the existing budget test.
    • Determinism: triggers are pure checks on round state, no RNG, so a seeded replay and the probe still hold.
    # maps/boot-camp.toml (sketch)
size = [48.0, 13.0]
mission.kind = "training"

[cells."10,5"]
kind = "door"
beat = "drive"

[[training.beat]]
id = "drive"
done = { flags = 3 }
frog = [5, 4]
say = ["frog-hello", "frog-drive", "frog-flags"]
nudge = "frog-drive-nudge"

[[training.beat]]
id = "frog"
start = { shoot_frog = "east", drop = "frog_health" }
done = { heal_frog = true }

[[training.beat]]
id = "enemy"
start = { roll_in = { gate = "east", tank = "scout", ai = "dummy" } }
done = { kill = 1 }
